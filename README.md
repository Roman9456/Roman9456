## 🚀 Now working on

**Business portal for a 1C integrator** · *private, in production*

> Clients fill in an adaptive pre-project survey; staff run the presale pipeline and prepare commercial proposals and work estimates.

- Adaptive survey that shows only relevant sections, export to Word / PDF, Google Drive and Telegram
- Presale workspace with an **LLM assistant**: company card by tax ID with web search, call scripts, mailings
- Commercial-proposal builder with live preview and **PowerPoint** export, A4-paginated estimates
- Staff sign-up with email codes, roles, admin panel; separate feedback service with Confluence and PDF

`FastAPI` `SQLAlchemy` `SQLite / PostgreSQL` `React` `Vite` `LLM API` `Google Drive API` `Passenger`
